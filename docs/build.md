Сборка проекта



Настройки сборки



В проекте используется Unity Build Profiles. Сейчас выбрана платформа Windows. Модули сборки для остальных платформ не установлены.



Сцены



Assets/IndieMarc/PlatformerDemo/PlatformerDemo.unity: Включена в сборку
Assets/IndieMarc/TopDownDemo/TopDownDemo.unity: Удалена и не включена в сборку



Платформы



В Build Profiles перечислены следующие платформы:



Windows, macOS, Linux;
Windows Server, macOS Server, Linux Server;
Android, iOS;
PlayStation 4, PlayStation 5;
Web;
Meta Quest, Android XR;
Universal Windows Platform;
tvOS, visionOS;
Embedded Linux, QNX.



Сборка сейчас доступна только для Windows. Для сборки под другие платформы нужно установить соответствующие модули.

Структура проекта



Основная часть проекта находится в папке Assets/IndieMarc/PlatformerDemo.



Editor/: Скрипты и инструменты для редактора Unity
Materials/: Материалы для игровых объектов
Prefabs/: Готовые шаблоны игровых объектов
Scripts/: Скрипты игровой логики
Sprites/: Спрайты и другая 2D-графика
Tilemap/: Ресурсы для создания уровней из тайлов
PlatformerDemo.unity: Основная сцена проекта

В папке Assets также есть папки Scenes, Settings и TutorialInfo.



Ассеты



В проекте есть спрайты персонажа, деревьев, травы, рычага и тайлов уровня, материалы, префабы, анимации персонажа и ресурсы Tilemap. Звуки и музыка отсутствуют.



Приблизительный размер проекта



Папка Assets/IndieMarc/PlatformerDemo: Около 1,87 МБ
Вся папка проекта, включая служебные файлы Unity: Около 1,17 ГБ



Полный размер включает папку Library, в которой Unity хранит автоматически созданные данные. Поэтому он может быть значительно больше размера исходных файлов проекта.
